# Superstore Sales Analysis

## Project Overview
Analisis data penjualan Superstore menggunakan SQL Server, Python, dan Power BI.

## Tools
- SQL Server
- Python (Pandas)
- Power BI

## Objectives
- Menganalisis performa penjualan
- Mengetahui kategori terlaris
- Mengetahui region dengan penjualan tertinggi
- Mengidentifikasi produk dengan kontribusi terbesar

## Key Insights
- Technology dan Furniture memiliki kontribusi penjualan terbesar.
- Region West menghasilkan penjualan tertinggi.
- Penjualan meningkat dari tahun 2014 hingga 2017.
- Beberapa produk memberikan kontribusi besar terhadap total revenue.
